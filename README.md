# CS232 – Computer Networks (UCI)

Course materials, assignments, and study notes for **CS232: Computer Networks** at the
University of California, Irvine. The repository collects the textbook chapters, lecture
references, homework problem sets, and exam-preparation material organized by topic and
by exam.

The course follows Kurose & Ross, *Computer Networking: A Top-Down Approach*, covering the
application, transport, network, and link layers.

## Topics Covered

- **Application layer** – HTTP, DNS, email, P2P, the client–server model
- **Transport layer** – UDP, TCP, reliable data transfer, flow & congestion control
- **Network layer** – IP addressing, routing algorithms, forwarding
- **Link layer & LANs** – multiple access protocols, switching, Ethernet
- Supporting math: exponential / Poisson processes for traffic and queueing analysis

## Usage

This is a reference and study repository. Browse the folders by topic or by exam
(`Midterm/`, `Final/`), read the homework prompts under `Assignments/`, and use the
topic-wise summaries in `ChatGPT/` and the Kurose chapters for review.
